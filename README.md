# multas-condominios-data

Base de datos (JSON) que alimenta el buscador de multas de condominios/comunidades
en administradoreschile.cl.

- Fuente: registros públicos de multas de la Dirección del Trabajo.
- Contenido: multas asociadas a comunidades, condominios, edificios y copropiedades,
  agrupadas por RUT.
- Consumo: se sirve vía jsDelivr y lo lee por `fetch` el widget embebido en Webflow.

URL pública (jsDelivr):
https://cdn.jsdelivr.net/gh/ComunidadFeliz-Interno/multas-condominios-data@main/multas_condominios.json
